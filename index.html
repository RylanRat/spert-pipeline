Auto-Deploy via GitHub
Connect to GitHub so the Upgrade Studio pushes changes directly. Netlify watches your repo and redeploys in ~30 seconds — no manual uploading ever.
One-time setup (8 min, free):
1. Create a GitHub repo — go to github.com/new, name it spert-pipeline, set Public, click Create.
2. Upload your file — in your new repo click Add file → Upload files, upload spert-pipeline.html, commit.
3. Connect Netlify to GitHub — go to app.netlify.com → Add new site → Import from Git → GitHub → pick your repo. Publish directory: /, build command: empty. Deploy.
4. Create a GitHub token — go to github.com/settings/tokens/new → Note: "Spert Deploy" → Expiration: No expiration → check repo scope → Generate → copy it.
5. Paste below and Save Keys. Every future upgrade auto-deploys in ~30 sec.
